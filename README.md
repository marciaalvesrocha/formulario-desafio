# Portfolio e Formulário de Contato - HTML5

Este projeto é uma página web simples desenvolvida como parte das atividades práticas do curso de **Desenvolvimento de Sistemas no SENAI**. Ele serve como um mini portfólio pessoal e formulário de contato, utilizando conceitos estruturais de HTML5 semântico.

---

## 📌 Funcionalidades

- **Navegação Interna:** Links de ancoragem para seções da página.
- **Sobre Mim:** Apresentação pessoal e lista de habilidades.
- **Tabela de Projetos:** Exibição dos projetos desenvolvidos com links diretos para os repositórios do GitHub.
- **Formulário de Contato:** Campos com validação básica (`required`), lista suspensa (`select`) e área de texto (`textarea`).
- **Links de Contato Direto:** Atalhos para envio de e-mail (`mailto:`) e ligação (`tel:`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântica, Tabelas, Formulários e Links)
- **CSS** (Estilização inline para formatação de listas)
